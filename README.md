# gasto-control- · Gastos V1

MVP de registro de gastos personales y de Carpintería El Roble (Next.js).

## Incluye
- Registro manual de gasto.
- Fecha, importe, descripción, ámbito, categoría, subcategoría y medio de pago.
- Separación Personal / Carpintería El Roble.
- Historial filtrable por mes, ámbito y búsqueda.
- Edición y eliminación.
- Totales mensuales y previsualización por categoría.
- Persistencia local en el navegador mediante localStorage.

## Ejecutar
```bash
npm install
npm run dev
```

Abrir http://localhost:3000
